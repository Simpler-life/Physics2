> **本讲主线**：电容、电感会储能 → 连接后能量来回交换，形成 LC 振荡 → 加电阻后能量流失，形成 RLC 阻尼 → 用交流电源不断补充能量，形成受迫振荡 → 电压和电流不同步，因此需要阻抗 $Z$ → 某个频率下电流最大，这就是串联共振。

## 0. 为什么前面学过 RC、RL，这里还要学 LC、RLC？

前面两讲分别讨论：
- **电容 $C$**：两个极板上分开储存正、负电荷，电场中储有能量。接通电阻后可以放电。
- **电感 $L$**：线圈中的电流产生磁场，磁场中储有能量。电流变化时电感出现自感电动势，阻碍电流突然变化。
- **电阻 $R$**：电流通过时把电能转成热，通常不把能量储存在可逆的电磁场中。

把三个元件放在一条回路里，会产生一个自然的问题：

> **如果没有电池，把原来已经充电的电容接到电感上，电容的能量去了哪里？**

这就是本讲的起点，而不是某个突然冒出来的交流公式。

### 先认识这一讲的字母

| 符号 | 含义 | 常见单位 | 不要混淆 |
|---|---|---|---|
| $q(t)$ | 某块电容极板上的**带符号电荷量** | C（库仑） | $C$ 也恰好是库仑的单位符号 |
| $Q_m$ | 电荷振幅（最大的电荷量绝对值） | C | 不随时间变化的振幅 |
| $i(t)$ | 按指定箭头方向计算的瞬时电流 | A | 正负号表示方向 |
| $I_m$ | 电流峰值/振幅 | A | 和有效值 $I_{\rm rms}$ 不同 |
| $v(t)$ | 瞬时电压 | V（伏特） | 有时教材用小写 $v$，不代表速度 |
| $V_m$ | 电压峰值 | V | 不是体积 |
| $R$ | 电阻 | $\Omega$ | 把电能转化为热 |
| $L$ | 电感 | H（亨利） | 不是线圈长度 |
| $C$ | 电容 | F（法拉） | 不是电荷量 |
| $t$ | 时间 | s | — |
| $f$ | 每秒振荡次数（频率） | Hz | — |
| $T$ | 振荡一次用的时间（周期） | s | 这里不是磁感应强度的单位 T |
| $\omega$ | 角频率，描述振荡快慢 | rad/s | $\omega=2\pi f$ |
| $\varphi$ | 相位角或相位差（要看上下文） | rad 或度 | 与磁通量 $\Phi_B$ 不同 |

这里所说的电路，在后半讲主要是**理想的串联 RLC 电路**，并且研究交流驱动后的**正弦稳态**，不能直接推广到所有任意电路。

## 1. 第一步：不接电源，也不接电阻——为什么 LC 会自己振荡？

### 1.1 先想象真实发生的过程

假设电容已经充电，随后接到理想电感上，线路电阻忽略不计。

1. **刚接通**：电容极板上的电荷量最大，电容两板有电压；电流还为零，所以电感的磁场能量为零。
2. **开始放电**：电容推动电荷流动，电流逐渐增大；电容的电场能量减少，而电感的磁场能量增加。
3. **电容恰好放空的瞬间**：电容电压为零，但电流不是零，反而达到最大。原因是电感不允许电流突然停下。
4. **电流继续流动**：由于电感维持电流，电容被反向充电；电流逐渐减小，能量又从磁场回到电场。
5. **反向充满后**：电流又瞬时为零，随后反向重复以上过程。

所以 LC 振荡不是“电荷凭空来回跑”，而是**电场能量与磁场能量反复交换**。

| 时刻 | 电容电荷大小 | 电流大小 | 电场能量 | 磁场能量 |
|---|---|---|---|---|
| 起始，充电最多 | 最大 | 0 | 最大 | 0 |
| 第 1/4 周期 | 0 | 最大 | 0 | 最大 |
| 第 1/2 周期 | 最大（符号反向） | 0 | 最大 | 0 |
| 第 3/4 周期 | 0 | 最大（电流方向反向） | 0 | 最大 |
| 完整一个周期 | 回到初始 | 0 | 最大 | 0 |

### 1.2 用能量解释：为什么总能量不变？

前面讲过两种储能：

- 电容的电场能量：电荷越多，储能越多。
- 电感的磁场能量：电流越大，储能越多。

用公式表达就是：

```math
U_C=\frac{q^2}{2C},
\qquad
U_L=\frac12 Li^2
```

其中 $U_C,U_L$ 的单位都是 J（焦耳）。若理想回路中没有电阻，也没有外界输入或输出能量，那么：

```math
U_{\rm total}=U_C+U_L=\text{常数}
```

不必先死背，关键是理解：**一个储能项减少，另一个就得增加。**

### 1.3 为什么变化会是正弦函数？

为了得到振荡的速度，需要用电路的电压关系。电容有 $v_C=q/C$；电感两端的电压与电流变化率有关。先统一选好电荷和电流的正方向，消去电流后，可以得到：

```math
L\frac{d^2q}{dt^2}+\frac{q}{C}=0
```

这里：
- $dq/dt$ 是电荷每秒变化多少；
- $d^2q/dt^2$ 是电荷变化率本身变化得多快；
- 第二项 $q/C$ 体现电容当前的电压。

这是和弹簧振子相同的数学结构：偏离平衡时，总有一种使系统返回的作用，但惯性使其越过平衡点。LC 中起类似“惯性”作用的是电感，类似“弹簧回复”作用的是电容。

它的一个解是：

```math
q(t)=Q_m\cos(\omega_0t+\phi_0)
```

$Q_m$ 是电荷振幅，$\phi_0$ 是初相位（决定从哪个时刻开始观察），$\omega_0$ 是**固有角频率**，也就是不用外部周期性电源时系统自身的振荡快慢。

把该解代回微分方程，才得到：

```math
\boxed{\omega_0=\frac1{\sqrt{LC}},
\qquad T_0=2\pi\sqrt{LC}}
```

理解趋势即可先过关：$L$ 越大，电流越难变化；$C$ 越大，同一电压下储存的电荷越多。二者增大都会使振荡变慢。

### 1.4 为什么电荷最大时电流为零？

电流表示电荷变化有多快。采用 $i=dq/dt$ 的方向约定时：

```math
i(t)=-\omega_0Q_m\sin(\omega_0t+\phi_0)
```

当余弦达到最大或最小时，曲线斜率为零，电流为零；当余弦经过零点时，曲线最陡，电流大小最大。

**记住的是“电荷变化率”这个关系，不是硬背正弦前面的负号。** 如果你的电流箭头与上述约定相反，电流公式的整体符号也要反过来。

## 2. 第二步：接入一个电阻，为什么振荡会越来越弱？

现在把电阻 $R$ 接入 LC 回路，成为**串联 RLC 自由振荡电路**，仍然不接外部交流电源。

电容储存的电场能量与电感储存的磁场能量仍然可以交换，但电流每经过电阻一次，电阻都会把一部分能量转化为热。因此总电磁能量下降。

可以把它类比成有摩擦的弹簧振子：仍然可能左右摆动，但幅度逐渐缩小。**这就是阻尼（damping）。**

写成方程：

```math
L\frac{d^2q}{dt^2}+R\frac{dq}{dt}+\frac qC=0
```

与上一节的 LC 方程相比，只多了中间的 $R\,dq/dt$，它描述耗散。

为了衡量耗散有多强，定义阻尼参数：

```math
\alpha=\frac{R}{2L}
```

- **欠阻尼**：$R$ 较小，仍会来回振荡，只是振幅衰减。
- **临界阻尼**：刚好达到不再振荡的分界。
- **过阻尼**：$R$ 更大，电荷不再来回过零振荡，而是以非振荡方式恢复平衡。

欠阻尼时，振荡的角频率变成：

```math
\omega_d=\sqrt{\omega_0^2-\alpha^2}
```

其中 $\omega_d$ 是**有阻尼的自由振荡角频率**，通常比理想 LC 的 $\omega_0$ 小；欠阻尼振幅的包络按 $e^{-\alpha t}$ 衰减。

**本节不要先背 $\omega_d$**。先回答：电阻越大，能量为什么越快耗掉？为什么如果耗散太强，系统甚至来不及反复交换能量？

## 3. 第三步：一直损失能量，如何让电路持续振荡？

答案是：**接入交流电源，让电源持续提供能量。**

交流电源不是给一个恒定电压，而是使电压周期性地变正、变负。最常见的正弦电源可写作：

```math
v_s(t)=V_m\cos(\omega t)
```

- $v_s(t)$：电源在时刻 $t$ 的瞬时电压；
- $V_m$：电压的最大绝对值（峰值）；
- $\omega$：由**电源指定**的角频率，并不是 LC 自己的 $\omega_0$。

必须区分：
- **自由振荡**：没有周期性外部驱动，节奏由电路自己的 $L,C,R$ 决定；
- **受迫振荡**：由外部交流源不断驱动；经过暂态后，稳态电流跟随**电源的频率 $\omega$**。

后面的阻抗公式，只讨论这种正弦稳态。

## 4. 第四步：为什么交流电路不能简单套用 $V=IR$？

先不考虑三个元件一起工作，分别观察它们。

### 4.1 电阻：电压与电流同步

电阻仍满足 $v_R(t)=Ri(t)$。电压大时电流按同一比例大，电压变号时电流也同时变号。正弦稳态下，二者**同相**。

### 4.2 电感：电流变化才产生明显的电压

电感两端满足（采用被动符号约定）：

```math
v_L(t)=L\frac{di(t)}{dt}
```

不是电流越大电感电压就一定越大，而是**电流变得越快，电感电压越大**。

例如电流刚好达到峰值时，它瞬时不再继续上升，导数为零，此时理想电感两端电压为零。对于正弦波，电感**电压超前电流 $90^\circ$**。

电源频率越高，电流在相同时间内改变得越快，因此电感表现出的幅值关系更“难通过”。定义：

```math
X_L=\omega L
```

$X_L$ 叫**感抗**，单位也是欧姆。它不是发热电阻，而是电感在指定正弦频率下的电压幅值与电流幅值之比。

### 4.3 电容：要想有电流，就必须持续充放电

电容满足 $q=Cv_C$。电流是电荷变化率：

```math
i(t)=C\frac{dv_C(t)}{dt}
```

当电容电压正在快速上升或下降时，充放电电流较大；当电容电压处于峰值、暂时不再变化时，电流反而为零。

对于正弦波，电容**电流超前电压 $90^\circ$**。频率越高，在相同电压峰值下电流越大，因此定义容抗：

```math
X_C=\frac{1}{\omega C}
```

$X_C$ 叫**容抗**，单位欧姆。它反映电容在指定正弦频率下的电压幅值与电流幅值之比。

### 4.4 先停一下：为什么说三者“不同步”很重要？

如果三个元件串联，它们通过的是**同一个瞬时电流**，但三个元件两端电压的峰值并不在同一时刻出现。

所以你不能把三个**电压峰值**简单加起来。**任一时刻的瞬时电压可以按基尔霍夫定律代数相加，但各自峰值一般不能直接相加。**

这正是需要引入“阻抗”的原因。

## 5. 第五步：终于引出阻抗 $Z$——它不是突然规定的公式

### 5.1 先定义它的用途

在正弦稳态的**串联 RLC** 中，我们想要像欧姆定律一样，用电源电压峰值算电流峰值：

```math
I_m=\frac{V_m}{Z}
```

这里的 $Z$ 是**阻抗的大小**，定义为：

```math
Z=\frac{V_m}{I_m}
```

先把它理解为“**这个频率下，整个串联电路的电压峰值与电流峰值的比例**”。它有 $\Omega$ 的单位，但不等于把元件看成三个发热电阻。

### 5.2 为什么感抗与容抗要相减？

对于同一个正弦电流：

- 电阻电压与电流**同相**；
- 电感电压**超前**电流 $90^\circ$；
- 电容电压**落后**电流 $90^\circ$。

因此，电感与电容电压的相位方向相反，两者的净效果可以用 $X_L-X_C$ 表示。它们的电压峰值贡献先互相抵消一部分。

但是电阻电压沿“同相方向”，与这部分“差了 $90^\circ$ 的方向”互相垂直，**不能再直接和它相加**。

### 5.3 为什么最后是平方根？

想象一个直角三角形：

- 一条直角边长 $I_mR$（电阻同相电压的幅值）；
- 另一条直角边为带符号的 $I_m(X_L-X_C)$（电感和电容合并后的正交分量）；
- 斜边长 $V_m$（电源总电压的幅值）。

于是按勾股定理：

```math
V_m^2=(I_mR)^2+[I_m(X_L-X_C)]^2
```

两边除以 $I_m^2$，才得到：

```math
\boxed{Z=\sqrt{R^2+(X_L-X_C)^2}}
```

**这是经过相位叠加得到的结论，不是三个电阻随便拼出的经验公式。**

如果之后学复数，串联电路可写成复阻抗 $\underline Z=R+\mathrm j(X_L-X_C)$；这里的 $Z=|\underline Z|$ 只表示其**大小**，而复数还保存了相位信息。不会复数暂时完全不影响用直角三角形解题。

### 5.4 从阻抗大小到复阻抗：为什么出现 $j$？

前面只讨论了**串联 RLC 的阻抗大小**，足以求总电流振幅；但遇到 Exercise 2 那种**有并联支路的交流电路**，还必须正确处理各支路的相位，因此需要复阻抗。

#### (1) $j$ 是什么？

电路中 $i$ 已经用于电流，因此用 $j$ 表示数学中的虚数单位（与数学课的 $i$ 相同）：

```math
j^2=-1,\qquad \frac1j=\frac{j}{j^2}=-j
```

它不是额外的物理元件，也不是电流大小。复数的实部和虚部分别编码相差 $90^\circ$ 的两个正交相位分量。**乘以 $j$，相位增加 $90^\circ$；乘以 $-j$，相位减少 $90^\circ$。**

#### (2) 三种理想元件的复阻抗：做题速查

在**线性电路的正弦稳态**中，以相同频率 $\omega=2\pi f$ 表示所有电压、电流的相量，定义

```math
\underline Z=\frac{\underline V}{\underline I}
```

这里下划线表示**复数相量**，而 $|\underline Z|$ 表示阻抗的大小（电压振幅与电流振幅之比）。电阻、理想电感、理想电容分别有：

| 元件 | 复阻抗 $\underline Z$ | 大小 $|\underline Z|$ | 元件电压相对于电流 |
| --- | --- | --- | --- |
| 电阻 $R$ | $R$ | $R$ | 同相 |
| 电感 $L$ | $j\omega L$ | $\omega L$ | 超前 $90^\circ$ |
| 电容 $C$ | $\dfrac1{j\omega C}=-\dfrac{j}{\omega C}$ | $\dfrac1{\omega C}$ | 落后 $90^\circ$ |

**一眼看懂符号**：电阻贡献实数部分，电感贡献正虚部，电容贡献负虚部。这些不是说电压、电流“变成了虚数”，而是方便保留正弦量的相位信息。

为什么会这样？例如给电感一个相量电流，其实际电流可写为 $i(t)=I_m\cos(\omega t)$。根据 $v_L=L\,di/dt$，电压相位比电流超前 $90^\circ$，大小比值为 $\omega L$，于是用 $j\omega L$ 同时记录大小与相位。电容由 $i=C\,dv_C/dt$ 同理得到 $1/(j\omega C)$。

特别注意电容的代数变形：

```math
\frac{1}{j\omega C}
=\frac1j\frac1{\omega C}
=-\frac{j}{\omega C}
```

其中最后的负号只来自 $j^2=-1$；不是把 $j$ 随意从分母移到分子。

#### (3) 复阻抗怎样串联、并联？

对**同一频率的正弦稳态**，用复阻抗计算的串并联规则与普通电阻形式相同，但运算对象是**复数**：

**串联：**

```math
\underline Z_{\rm series}=\underline Z_1+\underline Z_2+\cdots
```

**并联：**

```math
\frac1{\underline Z_{\rm parallel}}
=\frac1{\underline Z_1}+\frac1{\underline Z_2}+\cdots
```

两元件并联时还可写作：

```math
\underline Z_{\rm parallel}
=\frac{\underline Z_1\underline Z_2}{\underline Z_1+\underline Z_2}
```

**不要先把每个复阻抗取绝对值再相加或并联**，那样会丢失相位信息。应当先进行复数运算，最后才取 $|\underline Z|$ 求振幅。

串联 RLC 的复阻抗正好是：

```math
\underline Z
=R+j\omega L+\frac1{j\omega C}
=R+j\left(\omega L-\frac1{\omega C}\right)
```

所以前面 5.3 的结论实际上就是它的模：

```math
|\underline Z|
=\sqrt{R^2+\left(\omega L-\frac1{\omega C}\right)^2}
```

由此也看出：**原来的 $Z=\sqrt{R^2+(X_L-X_C)^2}$ 不是另一套规律，而是复阻抗取模后的结果。**

#### (4) Chapter 13 Exercise 2：什么时候必须用复阻抗？

题中 $3\,\mu\mathrm F$ 电容与 $0.2\,\mathrm H$ 电感串联，后面连接 $1\,\mathrm H$ 电感和 $100\,\Omega$ 电阻的并联支路，电源频率为 $60\,\mathrm{Hz}$。

先计算：

```math
\omega=2\pi(60)\simeq377\ \mathrm{rad/s}
```

三种元件的复阻抗：

```math
\underline Z_C=-j884.2\ \Omega,\qquad
\underline Z_{L1}=j75.4\ \Omega,\qquad
\underline Z_{L2}=j377.0\ \Omega
```

对右侧并联支路：

```math
\underline Z_p
=\frac{100(j377)}{100+j377}
\simeq93.43+j24.78\ \Omega
```

再与左侧元件串联：

```math
\underline Z_{\rm total}
=\underline Z_C+\underline Z_{L1}+\underline Z_p
\simeq93.43-j784.0\ \Omega
```

如果 $150\,\mathrm V$ 是**电压振幅**，则总电流振幅是 $150/|\underline Z_{\rm total}|$；但题目问的是 **$100\,\Omega$ 电阻的支路电流振幅**，还要先求并联两端的电压振幅，再除以 $100\,\Omega$。

**判断口诀：** 看到简单串联 RLC，可以用前面的平方根公式；看到串并联混合，先用复阻抗化简电路，最后再取模求振幅。相量和阻抗只适用于这里的线性正弦稳态分析，不能直接代替开关瞬间的暂态微分方程。

---

### 5.5 用一个数字例子核对理解

假设某个频率下：

- 电阻 $R=3\,\Omega$；
- 感抗 $X_L=8\,\Omega$；
- 容抗 $X_C=4\,\Omega$；
- 电源电压峰值 $V_m=10\,\mathrm V$。

先把电感与电容相反的相位效应相减，得到 $8-4=4\,\Omega$；再把它与同相方向的 $3\,\Omega$ 进行直角三角形合成：

```math
Z=\sqrt{3^2+4^2}=5\,\Omega
```

因此电流峰值为：

```math
I_m=\frac{10\,\mathrm V}{5\,\Omega}=2\,\mathrm A
```

注意：不是 $Z=3+8+4=15\,\Omega$。

## 6. 第六步：相位差 $\varphi$ 与有效值究竟在解决什么问题？

### 6.1 有了 $Z$，为什么还需要相位差？

$Z$ 的大小只能告诉我们“电流峰值有多大”，却不能告诉我们“**电流最高点和电源电压最高点是否同时出现**”。

定义 $\varphi$ 为**电源总电压的相位减去电流的相位**。从刚才的直角三角形可知：

```math
\tan\varphi=\frac{X_L-X_C}{R}
```

要用分子、分母的符号判断象限（通常 $R>0$，$\varphi$ 在 $-90^\circ$ 到 $90^\circ$ 之间）：

- $X_L>X_C$：电感占主导，$\varphi>0$，**电流落后电压**。
- $X_L<X_C$：电容占主导，$\varphi<0$，**电流超前电压**。
- $X_L=X_C$：$\varphi=0$，电压和电流**同相**。

### 6.2 为什么日常交流电使用“有效值”？

交流电流一直变，直接说某个瞬时电流不方便。有效值（rms, root mean square）定义为：**让相同电阻产生相同平均热功率的直流电流大小**。

对于正弦波，才有：

```math
V_{\rm rms}=\frac{V_m}{\sqrt2},
\qquad
I_{\rm rms}=\frac{I_m}{\sqrt2}
```

不要把“除以根号 2”误用到任意波形；它是正弦波的结果。

### 6.3 为什么平均功率还需要 $\cos\varphi$？

电感和电容在理想情况下会把储存的能量还给电路；并不是每一时刻电源做的功都最终转成热。只有与电流同相的电压分量，对一个周期内的平均能量耗散有净贡献。

所以：

```math
P_{\rm avg}=V_{\rm rms}I_{\rm rms}\cos\varphi
=I_{\rm rms}^2R
```

$P_{\rm avg}$ 是一个周期内的平均功率，单位 W；$\cos\varphi$ 称功率因数。等号右边只适用于这里讨论的理想串联 RLC，平均耗散发生在电阻 $R$ 中。

## 7. 第七步：为什么某个频率的电流会突然变大——串联共振

回忆阻抗的来源：电感与电容的相位贡献是反向的。

如果调整电源频率，使两者恰好相等，就会发生什么？

这时 $X_L=X_C$，电感与电容对**整个串联电路总电压**的正交分量抵消。于是 $Z$ 只剩下 $R$，阻抗最小、同样电压峰值下电流最大。

因为 $X_L=\omega L$，$X_C=1/(\omega C)$，让它们相等就得到：

```math
\omega_{\rm res}=\frac{1}{\sqrt{LC}},
\qquad
Z_{\rm res}=R,
\qquad
I_{m,\rm res}=\frac{V_m}{R}
```

这里指的是**理想串联 RLC 在固定电压幅值驱动下，稳态电流幅值达到最大**的共振。

注意两个容易误解的地方：

1. 共振时不是“电感、电容都没有电压”：它们各自可能有很大的电压，只是**相位相反而在总和中抵消**。
2. $\omega_{\rm res}$ 和第 1 节的无阻尼 LC 固有角频率数值相同；但它与第 2 节欠阻尼自由振荡的 $\omega_d$ 不同。三个名称对应不同问题，不能混为一谈。

## 8. 整节课连起来：你应该记住的是哪一条因果链？

**没有电阻和电源：** 电容与电感交换能量，产生理想 LC 自由振荡。

**加入电阻、仍没有驱动：** 一部分能量变成热，振荡衰减，严重时不再振荡。

**再加周期性交流电源：** 电源持续输入能量；暂态消失后，电流按照电源频率振荡。

**为什么出现 $Z$：** 电阻、电感、电容的电压不在同一相位，不能直接把三个峰值相加。把“同相”和“正交”的部分合成，才得到阻抗大小。

**为什么出现共振：** 调整频率后，感抗和容抗的相位贡献能完全抵消，此时串联电流峰值最大。

### 真正做题时按顺序判断

1. **有没有外部交流电源？** 没有则是自由振荡或暂态；有且已经稳定则可以考虑正弦稳态阻抗。
2. **题目求的是什么？** 电荷/电流随时间的变化、衰减速率、电流峰值、相位还是平均功率？
3. **电路是不是串联 RLC？** 不是就不能直接套本讲的串联阻抗平方根式。
4. **电源频率是多少？** 先求 $\omega=2\pi f$，再判断感抗和容抗。
5. **最后才挑公式**，并检查峰值 vs 有效值、自由振荡 vs 受迫振荡、频率 vs 角频率。
