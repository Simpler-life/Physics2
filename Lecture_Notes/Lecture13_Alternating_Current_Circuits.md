## 0. 先知道这节课究竟在问什么

LC 振荡、RLC 阻尼、交流强迫振荡、阻抗与共振。学习时把每一条公式还原成『什么量会随着什么条件变化』，避免死背一排字母。

## 1. 为什么 LC 会振荡

**一句话直觉**：电容电场能量与电感磁场能量来回交换；没有电阻就不耗散。

公式：

```math
U=\frac{q^2}{2C}+\frac{LI^2}{2}
```

公式：

```math
L\frac{d^2q}{dt^2}+\frac qC=0
```

公式：

```math
\omega_0=\frac1{\sqrt{LC}}
```

公式：

```math
T=2\pi\sqrt{LC}
```

**符号逐个认识**：q：电容上带符号的电荷；I=dq/dt：按统一方向定义的电流；L：电感；C：电容；ω₀：固有角频率；T：周期。

**小例子 / 易错提醒**：LC 中 √LC 有时间量纲，但它不是像 RC、RL 那样的衰减时间常数；周期是 2π√LC。

## 2. 电荷、电流与相位

**一句话直觉**：电流是电荷对时间的导数，因此两者相差四分之一个周期。

公式：

```math
q(t)=Q\cos(\omega_0t+\phi)
```

公式：

```math
I(t)=\frac{dq}{dt}=-\omega_0Q\sin(\omega_0t+\phi)
```

**符号逐个认识**：Q：电荷振幅；φ：初相位 rad；t：时间；ω₀：固有角频率。这里 I 正向随 q 的定义，若电流箭头取反，整体符号也变。

**小例子 / 易错提醒**：电荷达到最大时瞬时电流为零；电荷过零时电流大小最大。

## 3. 加入电阻：RLC 自由衰减

**一句话直觉**：电阻将能量转成热，振荡幅度随时间变小；电阻过大时可能不再振荡。

公式：

```math
L\ddot q+R\dot q+\frac qC=0
```

公式：

```math
\alpha=\frac R{2L}
```

公式：

```math
\omega_d=\sqrt{\frac1{LC}-\alpha^2}
```

**符号逐个认识**：R：电阻；q̇、q̈：一阶和二阶时间导数；α：阻尼率 s⁻¹；ω_d：欠阻尼角频率。公式 ω_d 为实数要求 α<ω₀。

**小例子 / 易错提醒**：欠阻尼时振幅包络 ∝e^(−αt)；临界阻尼 α=ω₀；过阻尼 α>ω₀。

## 4. 交流电源驱动与阻抗

**一句话直觉**：电阻、电容、电感对交流的影响不同：R 不引入相移，L 使电流滞后，C 使电流超前。

公式：

```math
v(t)=V_m\cos\omega t
```

公式：

```math
X_L=\omega L
```

公式：

```math
X_C=\frac1{\omega C}
```

公式：

```math
Z=\sqrt{R^2+(X_L-X_C)^2}
```

公式：

```math
I_m=\frac{V_m}{Z}
```

**符号逐个认识**：V_m：电压峰值；I_m：电流峰值；ω：外加交流角频率；X_L：感抗 Ω；X_C：容抗 Ω；Z：串联 RLC 阻抗的大小 Ω。以上为正弦稳态串联电路。

**小例子 / 易错提醒**：频率增加时 X_L 增大、X_C 减小；纯电阻电流与电压同相。

## 5. 相位差与有效值

**一句话直觉**：有效值是与同一个电阻产生相同平均发热功率的直流量。

公式：

```math
\tan\varphi=\frac{X_L-X_C}{R}
```

公式：

```math
V_{\rm rms}=\frac{V_m}{\sqrt2}
```

公式：

```math
I_{\rm rms}=\frac{I_m}{\sqrt2}
```

公式：

```math
P_{\rm avg}=V_{\rm rms}I_{\rm rms}\cos\varphi
```

**符号逐个认识**：φ：电源电压相位减去电流相位；rms：均方根值；P_avg：平均功率。有效值的峰值除 √2 只适用于正弦波。

**小例子 / 易错提醒**：X_L>X_C 时 φ>0，电流落后电压；X_C>X_L 时 φ<0，电流超前。

## 6. 串联 RLC 共振

**一句话直觉**：感抗与容抗恰好相等时反应性电压相互抵消，串联阻抗最小。

公式：

```math
\omega_{\rm res}=\frac1{\sqrt{LC}}
```

公式：

```math
X_L=X_C
```

公式：

```math
Z_{\rm res}=R
```

公式：

```math
I_{m,\rm res}=\frac{V_m}{R}
```

**符号逐个认识**：ω_res：串联理想 RLC 正弦稳态电流共振频率；其余符号如上。这里说的是电流振幅最大，不要与阻尼自由振荡频率 ω_d 混为一谈。

**小例子 / 易错提醒**：见到『共振频率』，先判断题目说的是串联交流电流共振还是有阻尼自由振荡。

## 7. 公式忘了怎么办：识题步骤

1. **先画图、标出已知量**，并给方向和正负号一个明确约定。
2. **用文字描述题目**：要求的是力、场、电压、电流、磁通量还是能量？
3. **回到本页对应小节**，先读「符号逐个认识」确认字母含义与单位。
4. **检查适用条件**：匀强/非匀强、稳恒/变化、理想/真实、断电/接电、串联/并联等。
5. **代入之前检查量纲和极限**：例如距离趋大是否合理、时间趋久是否回到稳态。
