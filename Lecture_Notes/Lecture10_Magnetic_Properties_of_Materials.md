## 0. 先知道这节课究竟在问什么

## 1. 磁偶极矩与外磁场

**一句话直觉**：磁性材料可想成大量微小磁偶极的集合。

公式：

```math
\vec\mu=NI\vec A
```

公式：

```math
\vec\tau=\vec\mu\times\vec B
```

公式：

```math
U=-\vec\mu\cdot\vec B
```

**符号逐个认识**：μ：磁偶极矩；N：匝数；I：环电流；A：面积矢量；τ：转矩；U：取向势能。

**小例子 / 易错提醒**：均匀磁场中小磁偶极一般受到力矩但合力为零；非均匀场可能还受净力。

## 2. 磁化强度 M

**一句话直觉**：宏观物体里的微小磁偶极矩叠加，用单位体积的磁偶极矩描述磁化。

公式：

```math
\vec M=\frac{d\vec\mu_{\rm total}}{dV}
```

**符号逐个认识**：M：磁化强度 A/m；μ_total：小体积内磁矩总和；dV：体积元。M 是矢量，不等于磁矩 μ 本身。

**小例子 / 易错提醒**：未磁化时许多微观磁矩方向无序，宏观 M 可以近似为零。

## 3. B、H、M 三个量

**一句话直觉**：把自由电流产生的激励与材料的响应区分开。

公式：

```math
\vec B=\mu_0(\vec H+\vec M)
```

公式：

```math
\vec M=\chi_m\vec H
```

公式：

```math
\vec B=\mu_0\mu_r\vec H
```

**符号逐个认识**：B：磁感应强度 T；H：磁场强度 A/m；M：磁化强度 A/m；χ_m：磁化率；μ_r=1+χ_m：相对磁导率。后两式只用于线性、各向同性材料近似。

**小例子 / 易错提醒**：真空中 M=0，B=μ₀H；不要无条件把 B=μH 用在有磁滞的铁磁材料上。

## 4. 磁介质的分类

**一句话直觉**：分类的关键是材料磁化方向及其是否随外场简单线性变化。

公式：

```math
\chi_m<0\quad\text{(抗磁，理想弱响应)}
```

公式：

```math
\chi_m>0\quad\text{(顺磁，弱响应)}
```

**符号逐个认识**：χ_m 为磁化率。抗磁性趋向反抗外场，顺磁性趋向沿外场磁化。铁磁体存在磁畴、非线性和磁滞，不能只用 χ>0 概括。

**小例子 / 易错提醒**：题目给 M、H 或 μ_r 时先弄清所在的材料假设；『磁铁一定吸引一切物体』是不对的。

## 5. 磁滞与剩磁

**一句话直觉**：铁磁体的 B–H 曲线可能取决于过去经历，这就是磁滞；外场降为零时仍可能留有磁化。

公式：

```math
\text{铁磁体一般不是固定常数 }\mu_r
```

**符号逐个认识**：剩磁：撤去外场后残留的磁响应；矫顽场：使磁化或磁感应强度按特定定义降至零所需反向场。

**小例子 / 易错提醒**：永久磁铁与变压器铁芯需求不同：前者需要保持磁化，后者倾向减小循环损耗。
