## 1. 电感是什么

**一句话直觉**：电流产生磁通；线圈电流改变时，自己的磁通也改变，并产生阻碍电流变化的电动势。

公式：

```math
L=\frac{N\Phi_B}{I}
```

公式：

```math
\mathcal E_L=-L\frac{dI}{dt}
```

**符号逐个认识**：L：自感系数，亨利 H；N：线圈匝数；Φ_B：单匝磁通量；I：电流；ℰ_L：自感电动势。只在几何与介质固定、线性条件下可把 L 当常数。

**小例子 / 易错提醒**：L 大意味着在同样电流变化速率下，自感作用更强；阻碍的是电流的变化，不是电流本身。

## 2. 长螺线管的电感

**一句话直觉**：通过 B≈μ₀nI、磁通 Φ=BA 可推得线圈电感与匝数平方相关。

公式：

```math
L\simeq\frac{\mu_0N^2 A}{\ell}
```

**符号逐个认识**：N：总匝数；A：截面积；ℓ：线圈长度；μ₀：真空磁导率。适用于长、密绕、真空/空气芯螺线管。

**小例子 / 易错提醒**：匝数加倍而几何保持其他量不变，L 增为四倍。

### 为什么长度在分母？两种写法的区别

长、密绕、空气芯螺线管内部近似有：

```math
B\simeq\mu_0 n I,\qquad n=\frac{N}{\ell}
```

其中 $n$ 是**单位长度的匝数**（单位 $\mathrm{m^{-1}}$），$N$ 是**总匝数**，$\ell$ 是线圈长度，$I$ 是电流。磁通量 $\Phi_B=BA$，电感定义 $L=N\Phi_B/I$，所以：

```math
L=\frac{N(BA)}{I}=\mu_0\frac{N^2A}{\ell}=\mu_0 n^2A\ell
```

**两个结论不冲突**：

- **固定总匝数 $N$**、截面积 $A$ 不变时，线圈拉长，单位长度匝数变少，所以 $L\propto1/\ell$。
- **固定匝密度 $n$**、截面积 $A$ 不变时，线圈加长意味着总匝数同时增加，所以 $L\propto\ell$。

不要只记「$L$ 与长度成反比」或「$L$ 与长度成正比」；**先判断保持不变的是 $N$ 还是 $n$**。

## 3. 电感储能

**一句话直觉**：电感像储存磁场能量的装置，电容储存电场能量。

公式：

```math
U_L=\frac12LI^2
```

公式：

```math
u_B=\frac{B^2}{2\mu_0}
```

**符号逐个认识**：U_L：磁场储能 J；u_B：真空中的磁场能量密度 J/m³；I：电流；B：磁感应强度。

**小例子 / 易错提醒**：电流加倍，储能变成四倍（L 不变）。

## 4. RL 电路的暂态

**一句话直觉**：电感电流不能在有限电压下瞬间跳变；通电后电流逐渐增加，断源后逐渐衰减。

公式：

```math
\tau_L=\frac LR
```

公式：

```math
I_{\rm rise}(t)=\frac{\mathcal E}{R}(1-e^{-tR/L})
```

公式：

```math
I_{\rm decay}(t)=I_0e^{-tR/L}
```

**符号逐个认识**：τ_L：时间常数；R：串联总电阻；ℰ：理想直流源；I₀：断源前电流。衰减式须存在连续的放电回路。

**小例子 / 易错提醒**：刚通电 I(0)=0（初始无电流），久后 I→ℰ/R；t=τ_L 时上升约 63.2%。

## 5. 互感与变压器思想

**一句话直觉**：一个线圈变化的电流使另一个线圈链接的磁通改变，产生互感电动势。

公式：

```math
\mathcal E_2=-M\frac{dI_1}{dt}
```

公式：

```math
M=\frac{N_2\Phi_{21}}{I_1}
```

**符号逐个认识**：M：互感系数 H；I₁：线圈 1 电流；N₂：线圈 2 匝数；Φ₂₁：由线圈 1 的电流穿过线圈 2 每匝的磁通。取向决定磁通与电动势的符号。

**小例子 / 易错提醒**：直流电流恒定时（忽略开关瞬间）互感电动势为零；交流变化才持续感应。

**相关错题复盘**：[Chapter 12 Exercise 9：互感、电流源做功与磁场能量](../Mistake/Chap12_Exercise09_Mutual_Inductance_Source_Work.md)（理想电流源固定电流、$W=\int VI\,dt$、互感交叉项）。
