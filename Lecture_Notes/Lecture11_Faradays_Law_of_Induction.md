## 0. 先知道这节课究竟在问什么

磁通量变化为什么产生感应电动势、楞次定律和运动导体。学习时把每一条公式还原成『什么量会随着什么条件变化』，避免死背一排字母。

## 1. 磁通量是什么

**一句话直觉**：磁通量衡量穿过指定曲面的磁场法向分量的总和，不是『磁场线数量』的精确计数。

公式：

```math
\Phi_B=\int_S\vec B\cdot d\vec A
```

公式：

```math
\Phi_B=BA\cos\theta\quad\text{(匀强场+平面)}
```

**符号逐个认识**：Φ_B：磁通量，韦伯 Wb；B：磁场 T；A：面积 m²；θ：磁场与面积法线的夹角，不是与平面的夹角。

**小例子 / 易错提醒**：B 平行于平面时 θ=90°，磁通量为零；B 垂直平面时磁通量最大。

**对应练习**：[Chap12 Ex07(c) 磁通与磁通链](../Mistake/Chap12_Exercise07_Coaxial_Cable_Flux_Linkage.md) — **难度 ★★★★★｜跨章节，注意不能直接以磁通/I 作为总自感**。

## 2. 法拉第电磁感应定律

**一句话直觉**：回路所链接的磁通量随时间变化，就出现感应电动势。

公式：

```math
\mathcal E=-\frac{d\Phi_B}{dt}
```

公式：

```math
\mathcal E=-N\frac{d\Phi_B}{dt}
```

**符号逐个认识**：ℰ：感应电动势 V；N：每匝磁通量相同的线圈匝数；t：时间。负号体现按选定正向的楞次定律。

**小例子 / 易错提醒**：磁通量可因 B、面积 A、夹角 θ 变化而改变；『有磁场』不等于『必有感应电流』。

## 3. 楞次定律判方向

**一句话直觉**：感应电流产生的磁场总在阻碍『磁通量的变化』，而非必然与外磁场反向。

公式：

```math
\mathcal E=-\frac{d\Phi_B}{dt}
```

**符号逐个认识**：方向约定：环路正向与曲面法向通过右手定则关联。

**小例子 / 易错提醒**：例：垂直纸面向外的磁通量正在增加，感应磁场应指向纸内，对应从纸面看顺时针感应电流。

## 4. 运动电动势

**一句话直觉**：导体在磁场中运动，导体内电荷受到 q(v×B) 推动并分离。

公式：

```math
\mathcal E=\int(\vec v\times\vec B)\cdot d\vec\ell
```

公式：

```math
|\mathcal E|=B\ell v
```

**符号逐个认识**：v：导体速度；ℓ：导体有效长度；第二式仅适合 v、B、导体方向互相垂直且匀强场。

**小例子 / 易错提醒**：一根长度 0.5 m 的杆以 2 m/s 垂直切割 0.3 T 磁场，电动势大小 0.3 V。

## 5. 感应电场与静电场的区别

**一句话直觉**：随时间变化的磁场产生非保守的旋涡电场，闭合环路积分一般不为零。

公式：

```math
\oint_C\vec E\cdot d\vec\ell=-\frac{d}{dt}\int_S\vec B\cdot d\vec A
```

**符号逐个认识**：E：感应电场；C：固定闭合回路；S：以 C 为边界的固定曲面。此式强调由变化磁场产生的电场；运动回路需额外处理运动项。

**小例子 / 易错提醒**：静电场满足闭合积分为零，不能把这一结论照搬到变化磁场问题。

## 6. 能量与磁阻尼

**一句话直觉**：机械外力做功可转成电阻热；楞次定律符合能量守恒。

公式：

```math
I=\frac{\mathcal E}{R}
```

公式：

```math
P_{\rm Joule}=I^2R
```

**符号逐个认识**：R：回路总电阻；I：感应电流；P：发热功率。

**小例子 / 易错提醒**：杆在磁场中匀速运动且回路含电阻时，通常需外力持续做功以维持速度。

2. **用文字描述题目**：要求的是力、场、电压、电流、磁通量还是能量？

4. **检查适用条件**：匀强/非匀强、稳恒/变化、理想/真实、断电/接电、串联/并联等。
5. **代入之前检查量纲和极限**：例如距离趋大是否合理、时间趋久是否回到稳态。
