## 0. 先知道这节课究竟在问什么

电流怎样产生、电阻为什么阻碍电流、电容怎样储存电荷。学习时把每一条公式还原成『什么量会随着什么条件变化』，避免死背一排字母。

## 1. 从电荷到电流

**一句话直觉**：电流不是某一个电子的速度，而是单位时间穿过截面的电荷量。

公式：

```math
I=\frac{dq}{dt}
```

公式：

```math
q=\int_{t_1}^{t_2}I(t)\,dt
```

**符号逐个认识**：I：电流，安培 A；q：穿过截面的电荷，库仑 C；t：时间，秒 s。约定电流方向为正电荷运动方向，金属电子通常反向运动。

**小例子 / 易错提醒**：若 2 s 内通过 6 C 电荷，平均电流为 3 A。电流的正负仅描述相对于选定方向的流向。

## 2. 电流密度与漂移速度

**一句话直觉**：同样的总电流通过粗细不同的导线，电荷的流动分布可能不同。电流密度描述单位面积上流过的电流。

公式：

```math
I=\int_S\vec j\cdot d\vec A
```

公式：

```math
I=n|q_c|Av_d
```

**符号逐个认识**：j：电流密度，A/m²；dA：带法向的面积元；n：单位体积载流子数；q_c：每个载流子的电荷；A：横截面积；v_d：漂移速率。第二式适用于均匀、单一载流子情形。

**小例子 / 易错提醒**：截面积加倍而电流不变时，若 n 不变，则漂移速率减半。不要把漂移速度与电信号传播速度混为一谈。

## 3. 电阻与欧姆定律

**一句话直觉**：电阻衡量某元件在给定条件下电压与电流的关系；电阻率刻画材料本身。

公式：

```math
R=\frac{V}{I}
```

公式：

```math
R=\rho\frac{\ell}{A}
```

公式：

```math
\vec j=\sigma\vec E,\qquad \sigma=\frac1\rho
```

**符号逐个认识**：R：电阻 Ω；V：两端电势差 V；ρ：电阻率 Ω·m；ℓ：导线长度 m；A：截面积；σ：电导率 S/m；E：内部电场。R=V/I 是工作点的比值，欧姆元件才在固定条件下保持 R 常数。

**小例子 / 易错提醒**：导线长度变两倍，其他不变，电阻变两倍；截面积变两倍，电阻变一半。

## 4. 电阻的功率

**一句话直觉**：电阻把电能转为热能。

公式：

```math
P=IV=I^2R=\frac{V^2}{R}
```

**符号逐个认识**：P：功率，瓦 W；I：电流；V：电阻两端电压；R：电阻。后三种写法对于欧姆电阻等价。

**小例子 / 易错提醒**：已知 2 A 经过 3 Ω 电阻，耗散功率为 12 W。

## 5. 电容的意义

**一句话直觉**：电容不是电荷总量，而是『电压每增加一伏，能额外存储多少电荷』。

公式：

```math
C=\frac{|Q|}{|\Delta V|}
```

公式：

```math
C_{\rm parallel}=\varepsilon_0\frac A d
```

公式：

```math
U_C=\frac{Q^2}{2C}=\frac12CV^2
```

**符号逐个认识**：C：电容，法拉 F；Q：一块极板上的电荷量绝对值；ΔV：两板电势差；ε₀：真空介电常数；A：板面积；d：板距；U_C：储存的电场能量。平行板式忽略边缘效应。

**小例子 / 易错提醒**：接上恒压电源后把板距减半：C 加倍，Q=CV 加倍；若先断开电源，Q 不变而 V=Q/C 减半。
