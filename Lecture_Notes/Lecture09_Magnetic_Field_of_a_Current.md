## 0. 先知道这节课究竟在问什么

电流如何生磁场、毕奥—萨伐尔定律、安培环路定律。学习时把每一条公式还原成『什么量会随着什么条件变化』，避免死背一排字母。

## 1. 毕奥—萨伐尔定律

**一句话直觉**：把导线分成许多短电流元，先算每一段贡献，再矢量相加。

公式：

```math
d\vec B=\frac{\mu_0}{4\pi}\frac{I\,d\vec\ell\times\hat r}{r^2}
```

**符号逐个认识**：μ₀：真空磁导率；I：电流 A；dℓ：沿电流方向的小线段 m；r：电流元到观察点距离 m；r̂：从电流元指向观察点的单位矢量。

**小例子 / 易错提醒**：方向先按 dℓ×r̂ 判断，再根据对称性把相互抵消的分量删去。

## 2. 无限长直导线

**一句话直觉**：距直导线越远，磁场越弱，磁场方向绕导线成圆。

公式：

```math
B=\frac{\mu_0 I}{2\pi r}
```

**符号逐个认识**：r：观察点到直导线的垂直距离；该式适用于足够长、可近似无限的细直导线。

**小例子 / 易错提醒**：用右手握住导线，拇指沿电流，四指方向就是 B。

## 3. 圆形电流环的轴线场

**一句话直觉**：圆环每段产生的横向场相互抵消，沿轴向的分量相加。

公式：

```math
B_z(z)=\frac{\mu_0 I a^2}{2(a^2+z^2)^{3/2}}
```

公式：

```math
B_{\rm center}=\frac{\mu_0 I}{2a}
```

**符号逐个认识**：a：圆环半径；z：轴线上观察点到环心的有向距离；I：电流。B_z 的方向由环电流的右手定则确定。

**小例子 / 易错提醒**：在 z=0 代入得环心公式，远处按 1/|z|³ 衰减。

## 4. 安培环路定律

**一句话直觉**：它对任何稳恒电流都成立，但只有充分对称时才能方便地从积分直接求 B。

公式：

```math
\oint_C\vec B\cdot d\vec\ell=\mu_0 I_{\rm enc}
```

**符号逐个认识**：C：选取的闭合积分路径；dℓ：沿路径的切向线元；I_enc：穿过路径所围任一曲面的净电流，正负由右手定则确定。

**小例子 / 易错提醒**：无限长直导线可取同轴圆路径，B 大小恒定且与路径相切，故 B(2πr)=μ₀I。

## 5. 长螺线管与环形螺线管

**一句话直觉**：安培环路法的优势体现在对称性强的绕组。

公式：

```math
B_{\rm solenoid}\simeq\mu_0 n I
```

公式：

```math
B_{\rm toroid}(r)\simeq\frac{\mu_0 NI}{2\pi r}
```

**符号逐个认识**：n：每米绕组匝数；N：总匝数；r：环形绕组内部距中心轴的半径。忽略端部效应与漏磁，默认真空或空气芯。

**小例子 / 易错提醒**：注意 n=N/ℓ；螺线管内部近似均匀，环形绕组内部 B 随 r 改变。

## 6. 无磁单极子与散度

**一句话直觉**：不同于电荷，磁场线不以某个磁荷为起点或终点。

公式：

```math
\oint_S\vec B\cdot d\vec A=0
```

公式：

```math
\nabla\cdot\vec B=0
```

**符号逐个认识**：S：任意闭合曲面；dA：外法向面积元。第一式是磁通量高斯定律，第二式是其微分形式。

**小例子 / 易错提醒**：闭合面净磁通量为零并不代表面上每一点 B 都为零。
