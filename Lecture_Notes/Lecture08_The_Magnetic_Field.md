## 1. 磁场与磁场力

**一句话直觉**：磁场线是闭合的；磁力总垂直于瞬时速度，所以单纯磁力不能改变粒子速率。

公式：

```math
\vec F_B=q\vec v\times\vec B
```

公式：

```math
F_B=|q|vB\sin\theta
```

**符号逐个认识**：q：粒子电荷 C（可正可负）；v：速度 m/s；B：磁感应强度 T；θ：速度与磁场夹角。× 是叉乘，方向用右手定则，负电荷反向。

**小例子 / 易错提醒**：当速度平行磁场 θ=0 时磁力为零；垂直时磁力最大。

## 2. 匀强磁场中的圆周和螺旋运动

**一句话直觉**：将速度分为平行 B 与垂直 B 的部分。垂直分量转圈，平行分量匀速前进。

公式：

```math
r=\frac{mv_\perp}{|q|B}
```

公式：

```math
\omega_c=\frac{|q|B}{m}
```

公式：

```math
T=\frac{2\pi m}{|q|B}
```

**符号逐个认识**：r：轨道半径 m；m：粒子质量 kg；v_⊥：垂直磁场的速率；ω_c：回旋角频率 rad/s；T：周期 s。非相对论近似。

**小例子 / 易错提醒**：只提高平行速度不会改变圆周半径，但会增大螺旋间距。

## 3. 同时存在电场和磁场

**一句话直觉**：电场力能做功，磁场力只改变运动方向；速度选择器让两力平衡。

公式：

```math
\vec F=q(\vec E+\vec v\times\vec B)
```

公式：

```math
v=\frac EB
```

**符号逐个认识**：E：电场强度 V/m；v=E/B 仅适用 E、B 和 v 两两垂直，且电场力与磁力方向相反的无偏转情形。

**小例子 / 易错提醒**：首先画 E、B、v 的方向，再判 q 的正负，别背一个脱离方向条件的 v=E/B。

## 4. 通电导线受力

**一句话直觉**：电流相当于大量运动电荷，磁场对电荷的力累积到导线上。

公式：

```math
d\vec F=I\,d\vec\ell\times\vec B
```

公式：

```math
\vec F=I\vec\ell\times\vec B
```

**符号逐个认识**：I：电流 A；dℓ：沿电流方向的短线元 m；ℓ：直导线的方向长度矢量；B：磁场。第二式适合匀强磁场内直导线。

**小例子 / 易错提醒**：同向电流的两根长平行线相互吸引，反向相互排斥。

## 5. 霍尔效应

**一句话直觉**：载流子受到横向磁力后在侧面堆积，形成反向电场直至平衡。

公式：

```math
|q|E_H=|q|v_dB
```

公式：

```math
|V_H|=\frac{IB}{n|q|t}
```

**符号逐个认识**：E_H：霍尔电场；V_H：横向霍尔电压；n：载流子数密度；q：单个载流子的带符号电荷；t：样品沿磁场方向的厚度。电流、磁场和测量电压的方向需要明确。

**小例子 / 易错提醒**：霍尔电压的符号能判断载流子类型；画图要先固定电流和磁场方向。

## 6. 电流环磁矩

**一句话直觉**：小电流环像小磁铁，在外磁场中会受到转动它的力矩。

公式：

```math
\vec\mu=NI\vec A
```

公式：

```math
\vec\tau=\vec\mu\times\vec B
```

公式：

```math
U=-\vec\mu\cdot\vec B
```

**符号逐个认识**：μ：磁偶极矩 A·m²；N：线圈匝数；I：电流；A：面积矢量，方向右手定则；τ：力矩；U：势能。

**小例子 / 易错提醒**：μ 与 B 同向势能最低，反向最高；不要把磁矩 μ 与真空磁导率 μ₀ 混淆。

## 7. 公式忘了怎么办：识题步骤

2. **用文字描述题目**：要求的是力、场、电压、电流、磁通量还是能量？

4. **检查适用条件**：匀强/非匀强、稳恒/变化、理想/真实、断电/接电、串联/并联等。
5. **代入之前检查量纲和极限**：例如距离趋大是否合理、时间趋久是否回到稳态。
