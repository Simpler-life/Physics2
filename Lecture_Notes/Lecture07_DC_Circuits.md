## 1. 电池与电动势

**一句话直觉**：电动势名字里有『力』，实质却是每单位电荷获得的能量，单位为伏特。

公式：

```math
\mathcal E=\frac{W_{\rm source}}q
```

**符号逐个认识**：ℰ：电动势 V；W_source：电源提供的能量 J；q：经过电源的电荷 C。理想电源维持端电压；真实电池还可能有内阻。

**小例子 / 易错提醒**：把电源想成把电荷从低电势『抬』到高电势的泵。

## 2. 基尔霍夫两条规则

**一句话直觉**：节点规则来自电荷守恒，回路规则来自能量守恒。

公式：

```math
\sum I_{\rm in}=\sum I_{\rm out}
```

公式：

```math
\sum_{\rm loop}\Delta V=0
```

**符号逐个认识**：I_in：流入节点的电流；I_out：流出节点的电流；ΔV：沿选定绕行方向经过元件时的电势变化。

**小例子 / 易错提醒**：沿电流方向跨电阻写 −IR，逆电流方向写 +IR；跨理想电源从负端到正端写 +ℰ。算出电流负值意味着真实流向和假设相反。

## 3. 串联和并联

**一句话直觉**：串联各元件电流相同，并联各支路两端电压相同。

公式：

```math
R_{\rm series}=\sum_i R_i
```

公式：

```math
\frac1{R_{\rm parallel}}=\sum_i\frac1{R_i}
```

**符号逐个认识**：R_i：第 i 个电阻；等效电阻指在外部两端看过去产生同样 I–V 关系的单个电阻。

**小例子 / 易错提醒**：2 Ω 与 3 Ω 串联是 5 Ω，并联是 6/5 Ω。

## 4. RC 电路充电与放电

**一句话直觉**：电容电压不能瞬间跳变（在有限电流下）；充电初始电容像短路，久后像开路。

公式：

```math
\tau=RC
```

公式：

```math
q_{\rm charge}(t)=C\mathcal E(1-e^{-t/(RC)})
```

公式：

```math
q_{\rm discharge}(t)=Q_0e^{-t/(RC)}
```

公式：

```math
I_{\rm charge}(t)=\frac{\mathcal E}{R}e^{-t/(RC)}
```

**符号逐个认识**：τ：时间常数 s；C：电容 F；R：电阻 Ω；t：接通或断开后的时间；Q₀：放电初始电荷；ℰ：直流电源电动势。以上针对简单串联 RC，初始充电为零。

**小例子 / 易错提醒**：t=τ 时充电完成最终电荷的约 63.2%；放电剩余约 36.8%。约 5τ 后接近稳态。

## 5. 有电介质的电容器

**一句话直觉**：介质极化通常使固定几何结构的电容增加。

公式：

```math
C=\kappa C_0
```

公式：

```math
C\simeq\kappa\varepsilon_0\frac A d
```

**符号逐个认识**：κ：相对介电常数（无量纲）；C₀：未填充介质时电容。第二式是假设均匀完全填充的理想平行板电容器。

**小例子 / 易错提醒**：分清『接电源 V 固定』和『断开电源 Q 固定』；前者插介质后 Q 增加，后者 V 降低。

2. **用文字描述题目**：要求的是力、场、电压、电流、磁通量还是能量？

4. **检查适用条件**：匀强/非匀强、稳恒/变化、理想/真实、断电/接电、串联/并联等。
5. **代入之前检查量纲和极限**：例如距离趋大是否合理、时间趋久是否回到稳态。
