# Exam · 考试复习入口

本目录存放应试复习的**知识提取、公式、错因与复盘**，不替代原有 `Lecture_Notes/`、`Math_for_Physics/` 和 `Mistake/` 的主线记录。

- [Midterm（期中）](Midterm/README.md)
- [Final（期末）](Final/README.md)

## 复习规则
1. 历年真题优先；其次是真题相似题（可出自课后题、PPT 或专门设计）；最后才是其他必要知识。
2. 老师 PPT 是课堂讲授范围和表述的首要依据；Chap 讲义作补充。
3. 尚未讲到的章节不提前系统学习，由学生确认授课进度后再纳入。
4. 题目明确标注：原卷真题 / 相似变式 / 基础诊断。
5. 不把“辨认出正确选项”等同于“能独立推导或解题”。
6. 每次复盘确认后更新对应的知识与 Mistake；保留尚未验证的状态，不杜撰掌握程度。

## Markdown 与 LaTeX 排版规则（强制）
- 中文文字或中文标点与行内公式 `$...$` 之间必须留空格，包括公式前与公式后。例如：`电场为 $E=kQ/r^2$ ，方向向右。`
- 独立公式前后保留空行，`$$` 必须分别独占起始行和结束行；复杂公式优先使用独立的 `math` fenced block。
- `math` 代码块前后保留空行；代码块内的 LaTeX 不做普通文本的空格替换。
- 每次提交之前检查以上规则及 GitHub 的 Markdown 公式显示；只修复格式，不擅自修改物理内容和掌握状态。
