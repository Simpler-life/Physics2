## 1. 原题模型和任务

无限大**接地导体平面**取 $z=0$。其上方有半径 $R$、净电荷 $Q$ 的**孤立带电导体球**，球心在 $z=d$，$R<d$。

拟解析稿记录的要求：

1. 给出边界条件。
2. 假定球心有等效点电荷，讨论其关于平面的电像。
3. 解释新电像为什么引发下一次电像。
4. 说明最终所需的电像数目，给出位置与电荷量的表达或递推。

**说明：** 这是多导体边界问题，不要将球心电荷直接当作未经验证的真实电荷均匀分布。镜像系统只在求解区域（平面上方、球外）等效。

## 2. 三个约束：边界条件先于镜像构造

接地平面电势：

```math
\varphi(x,y,0)=0
```

球面是**未知常数电势**：

```math
\varphi\bigl(x^2+y^2+(z-d)^2=R^2\bigr)=V_s
```

球未接地且净电荷给定：

```math
Q_{\rm sphere}=Q
```

通常还假定无穷远电势趋于 0。接地平面能与大地交换电荷，不能另加“平面总电荷为零”的约束；球不接地，必须保证其净电荷为 $Q$。

**用户原答：** 识别出接地平面 $\varphi=0$，并知道球面电势相同；但最初没有明确总电荷条件。后来已正确理解孤立/接地之别。

## 3. 初始平面镜像

将球心的一颗**虚拟等效电荷**记为 $q_0$，放在 $z=d$。

它关于平面的镜像为 $-q_0$，放在 $z=-d$。这一对满足平面 $z=0$ 处电势相消，但不保证球面等势。

**原思维误区：** 误以为每增加一个 $-q$ 就必须为“电荷守恒”补一个 $+q$。镜像电荷并非真实生成，是否需补额外像电荷由边界条件、球的净电荷约束决定，而非虚电荷的守恒。

## 4. 对球的再次镜像：大小和位置

初始平面下方的 $-q_0$ 距球心 $D_0=2d>R$。

对半径 $R$ 的球，外部点电荷 $q_{\rm ext}$ 距球心 $D$ 时，为使其在球面上的**非恒定电势部分**抵消，可在球内、朝向外电荷的方向设置一颗镜像：

```math
q_{\rm im}=-\frac{R}{D}q_{\rm ext},
\qquad
\ell=\frac{R^2}{D}
```

于是：

```math
q_1=\frac{R}{2d}q_0,
\qquad
\ell_1=\frac{R^2}{2d}
```

这里 $q_1$ 位于**球心向接地平面的方向**，即 $z_1=d-\ell_1$。

**用户表现：** 第一次已正确给出 $\ell_1=R^2/(2d)$，但把电荷量误写成 $q_1=(2d/R)q_0$，比例倒置。

**检验：** 因为 $R<d$，所以 $R/(2d)<1$，应当有 $|q_1|<|q_0|$，不是远处诱导出更大的球内镜像电荷。

**概念修正：** 追加球内镜像是为了恢复球面**等势**，而不是为了强制球面电荷“均匀”。导体处于静电平衡时，表面电荷可以不均匀。

## 5. 再次平面镜像 → 无限交替

新的球内 $q_1$ 位于 $z_1=d-R^2/(2d)$，它会破坏平面零电势条件，因此在 $z=-z_1$ 处补 $-q_1$。

再将 $-q_1$ 相对球面镜像，得到 $q_2$，如此往复。

令球内点列为 $(q_n,z_n)$，平面下方点列为 $(-q_n,-z_n)$，并取：

```math
z_0=d
```

定义每一步平面下方像电荷与球心的距离：

```math
D_n=d+z_{n-1}
```

递推公式：

```math
\boxed{
z_n=d-\frac{R^2}{d+z_{n-1}},
\quad
q_n=\frac{R}{d+z_{n-1}}q_{n-1}
\qquad (n\ge1)
}
```

**用户第二轮思路正确：** 知道下一次外部电荷距球心为 $2d-\ell_1$。修正之后，下一颗镜像大小应为：

```math
q_2=\frac{R}{2d-\ell_1}q_1
```

不是 $(2d-\ell_1)q_1/R$。

## 6. 孤立球总电荷如何约束 $q_0$

对整个球面作包围球内部镜像点列的高斯面，可得：

```math
\boxed{\sum_{n=0}^{\infty}q_n=Q}
```

平面下方的 $-q_n$ 在这个球形高斯面**外部**，不计入球的净电荷。

注意：**球心等效电荷 $q_0$ 通常不直接等于题目给定的 $Q$**；它由上述求和约束确定。拟解析稿提到还可以显式引入球心补偿电荷，再把同位置的多项合并进 $q_0$。两种写法本质一致。

形式上可定义无量纲序列 $a_0=1$、$a_n=q_n/q_0$，然后：

```math
q_0=\frac{Q}{\displaystyle\sum_{n=0}^{\infty}a_n}
```

题目只要求电荷量表达/递推时，不一定必须把此级数求成闭式。

## 8. 期中再训练建议

由易到难，先做标准真题再做变式：
1. 点电荷 + 接地无限平面（单个镜像）；考电势、力、感应电荷。
2. 点电荷 + 接地球（Kelvin 镜像）；考 $q_{\rm im},\ell$、电势和球面净电荷。
3. 点电荷 + 孤立中性/带电球；比接地球多一个球心补偿电荷。
4. 接地平面 + 孤立带电球；多次交替镜像，只要求前两轮和递推、净电荷约束。

**错误自检口诀：** 先判接地/孤立 → 写电势及总电荷约束 → 判断镜像区域 → 球镜像用 $R/D$ 与 $R^2/D$ → 检查每个边界 → 最后满足净电荷 $Q$。
