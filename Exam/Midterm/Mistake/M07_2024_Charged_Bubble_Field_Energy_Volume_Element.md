>
> **来源：** 用户上传的《24期中.pdf》（2024–2025 期中整理稿）第 2 题及 2026-11-09 手写解答。题目叙述为“原本不带电的泡泡，半径 $R_0$；现带电 $Q$、半径变为 $R$”。这里按均匀带电的薄球壳理想模型求**最终静电场能量**，不讨论泡膜的表面张力或从 $R_0$ 到 $R$ 的机械功。

## 一、题目要求

1. 以 $r=R$ 为界，求球内外电场 $\vec E(r)$。
2. 求电场能量密度 $w_E(r)$。
3. 通过对能量密度进行空间积分求最终静电能 $E_P$。

其中 **$R$ 是固定的球面半径；$r$ 是可变的空间坐标和积分变量。**

## 二、第 (1) 问：高斯定律（思路正确，变量混淆）

高斯定律：

```math
\oint \vec E\cdot d\vec A=\frac{Q_{\rm enc}}{\varepsilon_0}
```

球壳内部 $r<R$ 没有包围净电荷，依球对称性有 $\vec E=0$；球外 $r>R$ 包围 $Q$：

```math
\boxed{\vec E(r)=\begin{cases}0,&r<R,\\[3pt]\displaystyle\frac{Q}{4\pi\varepsilon_0r^2}\hat r,&r>R.\end{cases}}
```

**手写需要纠正：** 将球外电场写成 $Q/(4\pi\varepsilon_0R^2)$，这个只对应球面外侧 $r=R^+$，不能表示整个球外空间。表面处存在跳变，内外极限需分清。

## 三、第 (2) 问：能量密度（公式正确，变量混淆）

在真空中：

```math
w_E(r)=\frac12\varepsilon_0 E(r)^2
```

```math
\boxed{w_E(r)=\begin{cases}0,&r<R,\\[3pt]\displaystyle\frac{Q^2}{32\pi^2\varepsilon_0r^4},&r>R.\end{cases}}
```

手写基本系数 $1/(32\pi^2\varepsilon_0)$ 正确；注意 $r^4$ 而非固定的 $R^4$。能量密度单位是 **J/m³**。

## 四、第 (3) 问：本题主要错误——把能量密度直接对 $dr$ 积分

### 4.1 真实手写错误

用户原式（变量略标准化）：

```math
E_P\overset{\rm wrong}{=}\int_R^{+\infty}\frac{Q^2}{32\pi^2\varepsilon_0r^4}\,dr
```

**错误本质：** $w_E$ 是单位**体积**包含的能量；$dr$ 仅是一个**长度微元**，不能直接用于求三维空间总能量。这样结果会出现 $R^{-3}$，而不是正确的 $R^{-1}$。

正确的起点是三维体积分：

```math
\boxed{E_P=\iiint_{\rm space}w_E\,dV}
```

在球对称问题里，把球外空间分解为半径 $r$、厚度 $dr$ 的**薄球壳**。薄球壳的体积微元为：

```math
\boxed{dV=4\pi r^2\,dr}
```

这不是凭空多乘一个系数，而是**球面面积 × 薄层厚度**。

如果用完整球坐标，也可以写成：

```math
dV=r^2\sin\theta\,dr\,d\theta\,d\phi,\qquad\int_0^{2\pi}d\phi\int_0^\pi\sin\theta\,d\theta=4\pi
```

所以角度积分完成之后，才得到 $4\pi r^2dr$。

### 4.2 正确计算

```math
\begin{aligned}
E_P&=\int_R^\infty w_E(r)\,4\pi r^2\,dr\\
&=\int_R^\infty\frac{Q^2}{32\pi^2\varepsilon_0r^4}\,4\pi r^2\,dr\\
&=\frac{Q^2}{8\pi\varepsilon_0}\int_R^\infty r^{-2}\,dr\\
&=\frac{Q^2}{8\pi\varepsilon_0}\left[-\frac1r\right]_R^\infty\\
&=\boxed{\frac{Q^2}{8\pi\varepsilon_0R}}.
\end{aligned}
```

### 4.3 第二个错误：积分原函数算错

用户在遗漏体积元后，又将 $\int r^{-4}dr$ 算成类似 $-3/r^3$。实际：

```math
\int r^{-4}\,dr=-\frac1{3r^3}+C
```

注意幂函数积分法则：

```math
\int r^n\,dr=\frac{r^{n+1}}{n+1}+C,\qquad n\ne-1
```

而**正确的能量积分**因补齐球壳体积元后，变成更简单的：

```math
\int r^{-2}\,dr=-\frac1r+C
```

### 4.4 两种快速检验：防止考场再犯

**量纲检验：** 只有 $w_E\,dV$ 才是 J；$w_E\,dr$ 的单位是 J/m²，绝不可能是总能量。

**独立计算检验：** 绝缘薄球壳在真空中的静电能与同形状带电导体球壳相同。其电容为 $C=4\pi\varepsilon_0R$，所以：

```math
\boxed{E_P=\frac{Q^2}{2C}=\frac{Q^2}{8\pi\varepsilon_0R}}
```

还可检查：对于固定 $Q$，半径 $R$ 越大，最终静电场能量越小，符合 $E_P\propto1/R$。

## 五、考前迁移：怎样判断体积微元

| 对称性 | 常用体积微元（已完成相应角度/截面积积分） |
|---|---|
| 球对称，积分半径 | $dV=4\pi r^2dr$ |
| 圆柱对称、长为 $L$ 的薄圆柱壳，积分半径 | $dV=2\pi rLdr$ |
| 一维均匀截面为 $A$，沿长度积分 | $dV=A\,dx$ |

**原则：** 先看题目求的是线量、面积总量还是空间总量，再选 $dl$、$dA$ 或 $dV$；看到**能量密度**、**体电荷密度**、**质量密度**等以“每单位体积”定义的量，求总量默认需要体积分。
