## 2. 目前可写出的作业结果（不代表理解）

假定两回路的电流、磁通正向选取使互感项为 $+M$，并按 $i_k=\dot q_k$ 定义。

### (a) 耦合方程

```math
L\ddot q_1+M\ddot q_2+R\dot q_1+\frac{q_1}{C}=0
```

```math
L\ddot q_2+M\ddot q_1+R\dot q_2+\frac{q_2}{C}=0
```

### (b) 定义新变量，相加相减

```math
q_+=q_1+q_2,\qquad q_-=q_1-q_2
```

两式相加：

```math
\boxed{(L+M)\ddot q_++R\dot q_++\frac{q_+}{C}=0}
```

两式相减：

```math
\boxed{(L-M)\ddot q_-+R\dot q_-+\frac{q_-}{C}=0}
```

**关于 (b) 的确认：** 上面这**两个方程就是解耦后的 equations**。额外写 $L_+=L+M$、$L_-=L-M$ 只是给系数起“有效电感”的名字，并**不是另两个要求求解的方程**。若题目仅要求得到独立的方程，写到这里即可。

### (c) 令 $R=0$，与 LC 振荡方程比较

```math
\omega_+=\frac1{\sqrt{(L+M)C}},\qquad
\omega_-=\frac1{\sqrt{(L-M)C}}
```
