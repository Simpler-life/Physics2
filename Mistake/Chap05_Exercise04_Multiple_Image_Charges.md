# Chapter 5 Exercise 4：双接地平面镜像法——为什么必须有第三个镜像电荷

> 状态：✅ 已解决  
> 主题：Method of Image Charges / multiple grounded boundaries / repeated reflection

## 1. 原题

点电荷 $Q$ 位于：

```math
(d,d,0),qquad d>0
```

接地导体占据满足 $x<0$ 或 $y<0$ 的全部区域，因此真正的空区域为：

```math
x>0,qquad y>0
```

两块接地导体面分别是：

```math
x=0
```

和：

```math
y=0
```

要求：求导体对点电荷 $Q$ 的作用力。

---

## 2. 第一步：先确定求解区域和边界

真正需要求电场的区域是：

```math
x>0,qquad y>0
```

因为真实点电荷就在这个区域内。

因此两个边界分别是：

```math
x=0
```

和：

```math
y=0
```

两块导体都接地，所以必须同时满足：

```math
\boxed{
V=0
}
```

关键不是“让某几个点的电势为 0”，而是要让两个完整平面上都处处满足 $V=0$。

---

## 3. 我一开始的疑问：放两个镜像电荷够不够？

真实电荷为：

```math
+Q\text{ at }(d,d,0)
```

为了满足 $x=0$，先关于 $x=0$ 镜像：

```math
-Q\text{ at }(-d,d,0)
```

为了满足 $y=0$，再把真实电荷关于 $y=0$ 镜像：

```math
-Q\text{ at }(d,-d,0)
```

直觉上很容易认为：

> 两个边界，各放一个镜像电荷，应该就够了。

但这是错误的。

---

## 4. 为什么两个镜像电荷还不够

先看 $x=0$。

真实电荷：

```math
+Q\text{ at }(d,d,0)
```

和第一个镜像：

```math
-Q\text{ at }(-d,d,0)
```

关于 $x=0$ 对称，因此它们在 $x=0$ 上的电势会逐点抵消。

但是第二个镜像：

```math
-Q\text{ at }(d,-d,0)
```

也会在 $x=0$ 上产生电势。

此时它没有一个关于 $x=0$ 对称、符号相反的伙伴来抵消它。

所以：

```math
\boxed{
\text{第二个镜像在修复 }y=0\text{ 的同时，又破坏了 }x=0
}
```

同理，第一个镜像虽然修复了 $x=0$，却会对 $y=0$ 产生额外电势。

这就是为什么两个镜像不够。

---

## 5. 为什么第三个镜像一定是 $+Q$ at $(-d,-d,0)$

现在把第二个镜像：

```math
-Q\text{ at }(d,-d,0)
```

再关于 $x=0$ 做一次镜像。

位置变为：

```math
(-d,-d,0)
```

因为是 grounded plane 的镜像，电荷符号反转，因此得到：

```math
\boxed{
+Q\text{ at }(-d,-d,0)
}
```

这个第三个镜像有两个作用。

### 对 $x=0$

它与：

```math
-Q\text{ at }(d,-d,0)
```

关于 $x=0$ 对称、符号相反，因此两者在 $x=0$ 上逐点抵消。

### 对 $y=0$

它同时又与：

```math
-Q\text{ at }(-d,d,0)
```

关于 $y=0$ 对称、符号相反，因此两者在 $y=0$ 上也逐点抵消。

所以一个第三镜像同时补好了两个边界。

最终电荷配置为：

```math
\boxed{
+Q\text{ at }(d,d,0)
}
```

```math
\boxed{
-Q\text{ at }(-d,d,0)
}
```

```math
\boxed{
-Q\text{ at }(d,-d,0)
}
```

```math
\boxed{
+Q\text{ at }(-d,-d,0)
}
```

---

## 6. 最重要的镜像法误区

这道题最值得记住的不是“四个角上正负交替”，而是：

```math
\boxed{
\text{新加入的镜像电荷也会影响其他边界}
}
```

所以不能机械地想：

```math
\text{一个边界}
\Rightarrow
\text{一个镜像}
```

更正确的思路是：

1. 加入一个镜像去满足某个边界；
2. 检查这个新镜像是否破坏其他边界；
3. 若破坏，就继续把它对其他边界做镜像；
4. 一直进行到所有边界都同时满足条件。

这可以理解为一种 repeated reflection（反复镜像）。

---

## 7. 如何快速检查三个镜像是否正确

### 检查 $x=0$

在 $x=0$ 平面上：

- $(d,d,0)$ 的 $+Q$ 与 $(-d,d,0)$ 的 $-Q$ 配对抵消；
- $(d,-d,0)$ 的 $-Q$ 与 $(-d,-d,0)$ 的 $+Q$ 配对抵消。

因此：

```math
\boxed{
V(x=0)=0
}
```

### 检查 $y=0$

在 $y=0$ 平面上：

- $(d,d,0)$ 的 $+Q$ 与 $(d,-d,0)$ 的 $-Q$ 配对抵消；
- $(-d,d,0)$ 的 $-Q$ 与 $(-d,-d,0)$ 的 $+Q$ 配对抵消。

因此：

```math
\boxed{
V(y=0)=0
}
```

所以两个完整边界都满足 grounded condition。

---

## 8. 下一步求力时怎么做

真实点电荷受到导体的力，就等于三个镜像电荷对它的库仑力之和。

三个镜像分别位于：

```math
(-d,d,0),qquad
(d,-d,0),qquad
(-d,-d,0)
```

对应电荷：

```math
-Q,qquad -Q,qquad +Q
```

其中：

- 左侧 $-Q$ 给出沿 $-x$ 的吸引力；
- 下侧 $-Q$ 给出沿 $-y$ 的吸引力；
- 左下角 $+Q$ 给出沿 $+x,+y$ 方向的斥力。

由于几何关于 $x=y$ 对称，最终一定有：

```math
\boxed{
F_x=F_y
}
```

---

## 9. 一句话复盘

```math
\boxed{
\text{第三个镜像不是“额外猜出来”的，而是前两个镜像对另一边界再次做镜像的结果。}
}
```

下次遇到多个 grounded boundaries 时，最先问自己：

> 我刚加进去的镜像，在修复一个边界以后，会不会把另一个边界重新破坏？
