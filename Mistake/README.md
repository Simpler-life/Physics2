# Mistake

用于保存已经完成但具有复盘价值的错题与思维误区。

这里重点记录：
- 当时具体想错了什么；
- 为什么这个想法会出错；
- 正确的判断框架；
- 下次遇到同类题如何快速识别。

与其他目录的区别：
- `Lecture_Notes/`：课程知识主线；
- `Unresolved_Problems/`：尚未解决的问题；
- `Mistake/`：已经解决、但值得反复复盘的错题与误区。

命名建议：

```text
ChapXX_ExerciseYY_Short_Title.md
```
