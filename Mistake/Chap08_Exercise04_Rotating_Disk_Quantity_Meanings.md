# Chapter 8 Exercise 4：旋转带电圆盘——物理量到底代表什么？

> 状态：解法已讲解；概念仍需用题目巩固  
> 核心误区：把同一个符号 $dq$、$dA$、$A$ 当成可以直接互换的“微小量”，没有先确定**它属于哪个对象、定义在哪个位置或截面**。  
> 关键词：surface charge density / current / motional charge / magnetic moment / torque

## 1. 题目与主线

半径为 $R$ 的塑料圆盘，面电荷密度均匀为 $\sigma$，以角速度 $\omega$ 旋转；匀强磁场 $\mathbf B$ 与旋转轴垂直。求圆盘所受总磁力矩的**大小**。

核心方法：把圆盘分成许多**半径为 $r$、宽度为 $dr$ 的同心细圆环**。每个带电细圆环旋转时等效为一个电流环，先求其磁矩再累加。

## 2. 每个物理量到底属于谁？

**阅读顺序：先确定物理对象，再看量的定义，最后写公式。** 本题中的「小」有两种不同来源：沿半径划分的窄环很薄；观察截面在短时间内通过的电荷很少。这两个「小」不能直接认作同一个微分。

### 2.1 几何量：整个圆盘和当前细圆环

**$R$：圆盘总半径。** 是常数，也是径向积分上限。

**$r$：当前考察的细圆环半径。** 是积分变量，遍历 $0$ 到 $R$。

**$dr$：当前细圆环的径向宽度。** 它不是电荷走过的路程，也不是圆周方向的一小段长度。

**$dA_{\mathrm{material}}$：窄环材料占据的面积。** 近似等于圆周长乘环宽： 

```math
dA_{\mathrm{material}}=2\pi r\,dr
```

这里的面积属于**环带本身**，用于计算这条环带含有多少电荷。

### 2.2 电荷量：材料上「拥有多少」与截面上「通过多少」

**$\sigma$：圆盘的面电荷密度。** 单位 C/m²；可为正或负。描述每单位圆盘材料表面上的净电荷。

**$dq_{\mathrm{ring}}$：整个细圆环拥有的电荷。** 因为把圆盘沿半径切成非常薄的环，所以这个总电荷很小：

```math
dq_{\mathrm{ring}}
=\sigma\,dA_{\mathrm{material}}
=\sigma\,2\pi r\,dr
```

**$dQ_{\mathrm{pass}}$：在短时间 $dt$ 内，通过一个固定径向截线（限制在当前窄环宽度内）的电荷。** 它和 $dq_{\mathrm{ring}}$ 不是同一个量。前者描述**流过**，后者描述**拥有**。

电流的原始定义应写作：

```math
I_{\mathrm{ring}}=\frac{dQ_{\mathrm{pass}}}{dt}
```

在圆盘径向积分中，习惯把很薄窄环贡献的电流写成 $dI$；此时 $I_{\mathrm{ring}}$ 与 $dI$ 指的就是同一条**指定窄环的电流贡献**。不能把径向微元 $dI$ 误当作时间微分 $dQ_{\mathrm{pass}}$。

**$\lambda_{\mathrm{ring}}$：窄环沿圆周分布的线电荷密度。** 单位 C/m，定义为：

```math
\lambda_{\mathrm{ring}}
=\frac{dq_{\mathrm{ring}}}{2\pi r}
=\sigma\,dr
```

注意它与 $\sigma$ 的单位和定义都不同。

### 2.3 运动量：电荷怎样经过观察位置

**$\omega$：圆盘的角速度。** 若只论大小，写 $|\omega|$。

**$v$：半径 $r$ 处电荷的切向速率。** 不同半径对应不同速率：

```math
v=|\omega|r
```

**$T$：电荷转一圈的时间。** 由于圆盘刚性转动，各窄环周期相同：

```math
T=\frac{2\pi}{|\omega|}
```

### 2.4 电流：同一物理定义的两种算法

**$dI$：选定窄环形成的等效环电流贡献。** 它不是整张圆盘上「所有电流」的一个统一数值。

- **从周期看：** 一个周期内，这条环上全部电荷恰好经过固定观察位置一次。
- **从速度看：** 单位长度的电荷量乘以每秒经过的长度，就是每秒通过截面的电荷。

因此对电流的**大小**有：

```math
|dI|=\frac{|dq_{\mathrm{ring}}|}{T}
=|\lambda_{\mathrm{ring}}|v
=|\sigma\omega|r\,dr
```

特别记录：原先自己想到的「$dq$ 乘速度除以圆周长」**是正确的**。只要明确 $dq$ 是**整个窄环上的电荷**，这就是线密度乘速率。

### 2.5 磁矩：为什么又换了一个面积？

**$A_{\mathrm{loop}}$：当前等效闭合电流回路所围成的面积。** 对半径为 $r$ 的圆形闭合电流路径：

```math
A_{\mathrm{loop}}=\pi r^2
```

**它不是**窄环材料的面积 $dA_{\mathrm{material}}=2\pi r\,dr$。哪怕环的中间完全没有带电材料，电流路径仍围住完整的圆面积。

**$d\boldsymbol{\mu}$：当前窄环的磁矩贡献。** 对环电流，磁矩大小等于电流大小乘以**回路围成的面积**：

```math
|d\boldsymbol{\mu}|=|dI|A_{\mathrm{loop}}
=\pi|\sigma\omega|r^3\,dr
```

它带 $d$，是因为细圆环的**电流贡献**很小，而不是因为磁矩公式中的面积必须是微元面积。

**$\boldsymbol{\mu}$：整个圆盘的磁矩。** 是所有同心环磁矩的**矢量积分**；方向按正电荷的常规电流方向用右手法则判断。负电荷会使磁矩相对旋转角速度反向。

**$\boldsymbol{\tau}$：磁场对圆盘的总力矩。** 不是合磁力。它由磁矩与外磁场的叉乘决定：

```math
\boldsymbol{\tau}=\boldsymbol{\mu}\times\mathbf B
```

本题磁场与磁矩垂直，因此力矩的大小是 $\tau=\mu B$。

> **一句判断原则：** 面密度 $\sigma$ 乘的是材料上实际带电的面积；磁矩中的电流 $I$ 乘的是电流闭合路径围成的面积。看到同一个字母 $A$，要先问「哪个面积？」

## 3. 误区一：$I=dq/dt$，为什么还能写 $dI=dq/T$？

最开始的疑问是：电荷确实在移动，电流不是通过固定截面的电荷对时间的变化率吗？

这恰好是正确的定义。关键在于**不要把两种 $dq$ 混为一谈**：

- $dq_{\mathrm{ring}}$：沿半径切分时，一整条窄圆环拥有的电荷。其微小，是因为环宽 $dr$ 很小。
- $dQ_{\mathrm{pass}}$：固定在圆周某处的观察截面，在时间 $dt$ 内通过的电荷。其微小，是因为时间 $dt$ 很短。

若 $\sigma$ 均匀且圆盘匀速旋转，窄环上的全部电荷会在一个周期 $T$ 内恰好经过观察位置一次，因此：

```math
|dI|=\frac{|dq_{\mathrm{ring}}|}{T}.
```

这并没有替换或否定电流定义，反而是用定义在一个周期内求稳定电流。

### 用户自己提出的、同样正确的速度法

窄环上沿圆周的线电荷密度为：

```math
\lambda_{\mathrm{ring}}=\frac{dq_{\mathrm{ring}}}{2\pi r}.
```

经过固定位置的电荷流率等于线密度乘切向速率：

```math
|dI|=|\lambda_{\mathrm{ring}}|v
=\frac{|dq_{\mathrm{ring}}|}{2\pi r}|\omega|r
=\frac{|\omega|}{2\pi}|dq_{\mathrm{ring}}|.
```

二者等价，因为 $T=2\pi r/v$。所以“**总电荷 × 速度 ÷ 周长**”不是错法，而是更直观的电流定义。

代入窄环总电荷：

```math
|dq_{\mathrm{ring}}|=|\sigma|\,2\pi r\,dr
\quad\Rightarrow\quad
|dI|=|\sigma\omega|\,r\,dr.
```

## 4. 误区二：为什么计算磁矩不用圆环的 $dA$？

这道题存在两个**不同含义**的面积：

### （A）窄环材料面积：用来数电荷

想象半径为 $r$、宽度为 $dr$ 的薄薄环带：它实际占据的面积是

```math
dA_{\mathrm{material}}=2\pi r\,dr.
```

因此：

```math
dq_{\mathrm{ring}}=\sigma\,dA_{\mathrm{material}}.
```

### （B）闭合电流路径包围的面积：用来算磁矩

即便圆环内部是空的，只要电流沿半径为 $r$ 的闭合圆周流动，这个电流回路包围的区域就是完整的圆盘：

```math
A_{\mathrm{loop}}=\pi r^2.
```

**磁矩公式 $\mu=IA$ 中的 $A$ 指电流回路所围面积，而不是导线本身横截面积，也不是带电材料实际占据的面积。**

因此对一个细圆环的磁矩贡献：

```math
|d\mu|=|dI|\,A_{\mathrm{loop}}
=|dI|\,\pi r^2
=\pi|\sigma\omega|r^3\,dr.
```

这里 $d\mu$ 之所以是微量，是因为**参与的电流 $dI$ 很小**，并非因为它乘的面积也必须是 $dA$。

## 5. 正确计算：先数电荷，再得到电流，再算磁矩，最后力矩

假设角速度是绕固定轴的矢量 $\boldsymbol\omega$；$\sigma$ 可带正负号。每条环的磁矩方向都与 $\sigma\boldsymbol\omega$ 一致：

```math
dq_{\mathrm{ring}}=\sigma\,2\pi r\,dr
```

```math
dI=\frac{\omega}{2\pi}\,dq_{\mathrm{ring}}
=\sigma\omega r\,dr
```

这里 $\omega$ 是选定轴向之后的带符号角速度；以上 $dI$ 也带方向约定。

```math
d\mu=\pi r^2\,dI
=\pi\sigma\omega r^3\,dr
```

```math
\mu=\int_0^R d\mu
=\pi\sigma\omega\int_0^R r^3\,dr
=\frac{\pi\sigma\omega R^4}{4}.
```

磁矩沿旋转轴（若 $\sigma<0$ 则反向）。由于外磁场与该轴垂直，问力矩**大小**时：

```math
\boxed{|\boldsymbol\tau|=|\boldsymbol\mu\times\mathbf B|
=\frac{\pi|\sigma\omega|BR^4}{4}}.
```

## 6. 更一般的复盘：符号和公式之前先追问四件事

1. **对象是谁？** 圆盘、薄圆环、单个电荷，还是固定截面？
2. **在哪里定义？** 材料表面、沿圆周的路径、还是电流回路包围的整个面？
3. **单位是否一致？** $\sigma$ 是 C/m²，$\lambda$ 是 C/m，$I$ 是 C/s，$\mu$ 是 A·m²，$\tau$ 是 N·m。
4. **为什么有 $d$？** 是因为径向积分、短时间流过截面，还是在累加许多环的磁矩？
