  - $\vec r_{12}=\vec r_2-\vec r_1$
  - $\hat r/r^2=\vec r/r^3$

- 🟡 **向量分量与对称性**
  - 已在圆盘电场中使用“横向分量抵消、轴向分量相加”

- ⬜ **点积 Dot Product**
  - $A\cdot B=AB\cos\theta$
  - 电通量、功中的应用

- ⬜ **叉积 Cross Product**
  - 右手定则
